# APT 시세 레이더 (Apt-Radar)

국토교통부 실거래가 기반 아파트 시세 분석 웹앱. 지역·단지별 매매 추이, 전세가율, 비교, 지도 시각화를 제공합니다.

- 배포: https://apt-radar-ashen.vercel.app
- 저장소: HMJeon-Cloud/Apt-Radar

---

## 1. 파일 구성

- `index.html` — 프론트엔드 전체 (단일 파일). 화면·차트·지도·모든 로직 포함.
- `vendor-chart.js` — Chart.js v4.4.4 (로컬 포함. CDN 차단 대비).
- `api/trades.js` — Vercel 서버리스 함수. 국토부 매매·전월세 API 프록시.

배포 구조: GitHub 저장소 → Vercel 자동 배포. 정적 프론트 + 서버리스 1개.

---

## 2. 키 / 환경 변수

1. **국토부 API 키** (`MOLIT_API_KEY`) — Vercel 환경 변수.
   - 공공데이터포털 "아파트 매매 실거래가 상세자료" + "전월세 실거래가 자료" 활용신청.
   - 반드시 **Decoding 키** 사용 (코드가 인코딩 처리. Encoding 키 넣으면 이중 인코딩 → 코드 30 오류).
   - 등록 후 Vercel Deployments에서 **Redeploy** 해야 반영.

2. **카카오맵 JavaScript 키** — `index.html`의 `var KAKAO_JS_KEY = '...'`.
   - "동네 축구왕" 앱(ID 1512620) JavaScript 키 재사용 (무료 쿼터 공유).
   - 카카오 개발자센터에서 해당 앱에 배포 도메인 등록 필수.
   - JS 키는 노출돼도 됨(도메인 제한이 보안 역할).

## 4. 핵심 상수 (index.html 상단, 조정 가능)

- `MAX_CONCURRENT = 8` — API 동시 요청 상한. 느리면 올리고, 502 잦으면 내림.
- `MAX_RETRY = 2` — 실패 요청 재시도 횟수.
- `MIN_SAMPLES = 3` — 전세가율 최소 표본. 올리면 엄격(노이즈↓ 데이터↓).
- `REGIONS` — 지원 지역(법정동코드 5자리 + 이름 + 데모 base). 지역 추가 시 여기에.
- `KAKAO_JS_KEY` — 카카오맵 키.
- 캐시 키: `apt_c:`(월별 실거래), `apt_geo:`(단지 좌표), `aptradar_favs_v1`(즐겨찾기).

## 5. 데이터 흐름

1. 프론트가 월별 `/api/trades?lawd={5자리}&ym={YYYYMM}&kind={sale|rent}` 호출.
2. 프록시가 국토부 API(XML) → JSON 변환 반환. 확정 과거월은 CDN 캐시(하루).
3. 프론트가 월별 결과를 localStorage 캐시(확정월만). 재조회 시 캐시 우선.
4. 집계(평당가·거래량·전세가율) → Chart.js 렌더.
5. 지도: 단지명 + 지역 중심 좌표로 카카오 장소검색 → 좌표 캐시 → 가격 핀.

데모 폴백: API 미연결 또는 매매 전월 실패 시, 결정적 난수 가상 데이터로 동작(배지 "데모 데이터").

## 6. 반복 발생 가능한 이슈

- Encoding/Decoding 키 혼동 → 코드 30 "등록되지 않은 서비스키". Decoding 키 사용.
- 키 활성화 지연 → 활용신청 후 1~2시간(최대 24h). 그 전 코드 30은 정상.
- CDN 차단 → 브라우저 추적방지가 외부 스크립트 차단. Chart.js는 로컬 포함으로 해결.
- 신고 지연 → 실거래 신고 계약 후 30일. 최근 2개월 불완전 → 캐시 제외, 전월까지만 조회.
- 지도 도메인 미등록 → "Kakao SDK 로드 실패". 카카오 앱에 배포 도메인 등록. 도메인 변경 시 추가.
- 지도 오검색 → 단지명 검색이라 동명 단지로 튈 수 있음. 지역 중심+반경+거리검증으로 완화. 데모 데이터는 가상 단지명이라 부정확(실데이터에서만 정확).
- 카카오 무료 쿼터 → 개발자 계정당 첫 앱만 무료. 그래서 기존 앱 키 재사용 + 좌표 캐시로 호출 최소화.

## 7. 검증 절차 (배포 후)

1. 프록시 단독: `/api/trades?lawd=43113&ym=202606&kind=sale` → `{count, items}` JSON.
2. 전세: `...&kind=rent` → `deposit`, `monthly`, `jeonse` 필드 확인.
3. 메인: 조회 → 배지 초록("실거래 API 연결됨") + 실제 단지명.
4. 비교/지도: 콘솔 에러 없이 렌더(favicon 404는 무시).
