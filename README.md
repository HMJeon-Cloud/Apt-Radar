# APT 시세 레이더 v0.1

아파트 실거래가 시기별 변동 확인 웹앱. 국토교통부 공공데이터 API 기반.

## 파일 구성

- `index.html` : 프론트엔드 전체 (단일 파일, Chart.js CDN 사용)
- `api/trades.js` : Vercel 서버리스 함수. 국토부 실거래가 API 프록시 (API 키 보호 + CORS 우회 + XML→JSON 변환 + 캐시)

## 배포 절차 (Vercel 기준)

1. GitHub에 새 저장소 생성 → `index.html`, `api/trades.js` 업로드 (웹 UI 가능, 폴더 구조 유지)
2. 공공데이터포털(data.go.kr) 회원가입 → "국토교통부_아파트 매매 실거래가 자료" 활용신청 → 마이페이지에서 **Decoding 인증키** 복사
3. Vercel에서 해당 저장소 Import → Settings > Environment Variables에 `MOLIT_API_KEY` = (2에서 복사한 키) 추가 → Deploy
4. 배포 URL 접속 → 지역 선택 후 조회

## 검증 절차

1. **데모 모드 확인**: `index.html`을 로컬에서 열면 우측 상단 배지가 "데모 데이터"(노란색)여야 함. 차트/카드/테이블이 모두 채워지면 프론트 정상.
2. **프록시 단독 확인**: 배포 후 브라우저에서 `https://<배포주소>/api/trades?lawd=43113&ym=202606` 직접 호출 → `{"count": N, "items": [...]}` JSON이 나오면 정상. `error`가 나오면 환경변수 또는 키 승인 상태 확인.
3. **연동 확인**: 메인 페이지에서 조회 → 배지가 "실거래 API 연결됨"(초록색)으로 바뀌고 실제 단지명이 테이블에 표시되면 완료.

## 주의사항 (반복 발생 가능)

- 공공데이터포털 키는 활용신청 후 **1~2시간(최대 24시간) 뒤 활성화**. 그 전에는 `SERVICE_KEY_IS_NOT_REGISTERED` 오류가 정상.
- 인증키는 **Decoding 키**를 환경변수에 넣을 것 (코드에서 `encodeURIComponent` 처리함. Encoding 키를 넣으면 이중 인코딩으로 인증 실패).
- 실거래 신고는 계약 후 30일 이내 → 최신 월 데이터는 불완전. 프론트는 전월까지만 조회하도록 되어 있음.
- API 일일 트래픽 제한(개발계정 기본 1,000건/일). 24개월 조회 = 24건 호출이므로 여유 있으나, `s-maxage` 캐시가 이를 보호함.
